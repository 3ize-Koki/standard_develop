# ウォーターフォール実務マニュアル

実作業において「どの数値をどうやって集めるか」のガイドです。
具体的な合格基準（%や件数）は `quality_standards_master.md` を参照してください。

- **見積もり時**: WBSと見積もりExcelを用意し、PERT法の期待値が使われているか確認します。
- **要件定義時**: 顧客合意の証跡（メールやBacklogのコメント）を揃えます。
- **テスト時**: SonarQubeやGitHubの解析結果、BTS（バグトラッキング）からバグ密度を算出します。
- **リリース時**: 脆弱性スキャン結果と、リハーサル結果の報告書を揃えます。
