# アジャイル実務マニュアル

スプリント開発において、「どのタイミングで、何を証跡として残し、品質会議にかけるか」のガイドです。
具体的な合格基準（%や件数）は `quality_standards_master.md` を参照してください。

## 品質会議の実施タイミングと準備
アジャイルプロジェクトでは、毎スプリントのレビューとは別に、**月1回の品質会議（マネジメント報告）**を実施します。

### ① スプリント0（プロジェクト開始前）
* **タイミング**: 最初の開発スプリント（スプリント1）を開始する前
* **準備するデータ**: 準委任等の契約書、MVP定義（Wiki等）、インセプションデッキ。

### ② 月次品質会議（スプリント定期評価）
* **タイミング**: 毎月末（当月実施したすべてのスプリントを対象に評価）
* **準備するデータ**: 
  * 当月の各スプリントのベロシティ推移と、直近3ヶ月分の平均ベロシティデータ（Jiraやスプレッドシート等で可視化）。AIでのトレンド評価に必須です。
  * 当月末時点でのSonarQube等の静的解析・カバレッジ結果。
  * 当月発生したバグのチケット総数。

### ③ 本番（メジャー）リリース前
* **タイミング**: 初期MVPのリリース時や、大規模な新機能を一般公開する直前
* **準備するデータ**: ペネトレーションテストやコンテナ脆弱性スキャンのレポート、監視テストの完了証跡。
