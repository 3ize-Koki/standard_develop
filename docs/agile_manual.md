# アジャイル実務マニュアル

スプリントを回す中で「何を証跡として残すか」のガイドです。
具体的な合格基準（%や件数）は `quality_standards_master.md` を参照してください。

- **スプリント0**: 契約書とインセプションデッキをWiki等に置きます。
- **スプリント完了時**: 
  - 過去3スプリント分のベロシティ（ストーリーポイント消化実績）をスプレッドシートやJira等で可視化しておきます。AIに入力する際にこのトレンドデータが必要になります。
  - SonarQube等の結果を毎スプリント残します。
- **リリース前**: ペネトレーションテストやコンテナ脆弱性スキャンの結果を揃えます。
