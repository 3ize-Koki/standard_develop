# ソフトウェア品質基準 実践リポジトリ

本リポジトリは、株式会社トリプルアイズ向けの「ソフトウェア品質基準」を管理し、AIエージェントを活用して品質会議用の評価レポートや**プレゼン資料（スライド構成）を自動生成**するためのプロンプトおよびマニュアル群です。

## 📁 ディレクトリ構成と役割
本リポジトリは「唯一の評価基準（Single Source of Truth）」を中心に、人間用とAI用のドキュメントが分離されたアーキテクチャになっています。

* **`quality_standards_master.md`** (⭐️最重要)
  * 品質評価の**唯一の基準書（製本版マスター）**です。具体的な判定基準（カバレッジ80%など）はすべてここに集約されており、人間もAIもこのファイルを参照します。
* **`docs/`** (人間向け)
  * 実務担当者（PL・開発チーム）が、各フェーズで「どのデータをどうやって集めるか」を記載した実務マニュアルです。
* **`skills/`** (AI向け)
  * AIエージェントに設定するシステムプロンプト（指示書）です。

---

## 🚀 使い方（AIへの指示とセットアップ）

お使いのAI環境（ChatGPTのCustom GPTs、Claude Projects、Difyなど）に合わせて、以下の手順でセットアップしてください。

### 【ステップ1：AIのセットアップ】
1. **ナレッジ（Knowledge）の追加**:
   `quality_standards_master.md` をAIの参照用ファイル（ナレッジベース）としてアップロードします。（※AIが具体的な数値を独自に捏造するのを防ぐため、必ずアップロードしてください）
2. **システムプロンプト（Instructions）の設定**:
   用途に応じて、以下のどちらかの内容をAIのシステム指示（System Prompt）に設定します。
   * ウォーターフォール用: `skills/waterfall_ppt_agent.md`
   * アジャイル用: `skills/agile_ai_agent.md`

### 【ステップ2：評価の実行（入力例）】

#### 📌 ウォーターフォールの場合（スライド資料の生成）
ユーザーは対象の工程と実績データをAIに入力します。

> **ユーザー入力例:**
> 現在の工程：③ テスト後
> プロジェクト状況：
> - テストカバレッジは75%でした。
> - 結合テストのバグ密度は1.2件/KSLOC、テスト密度は25件/KSLOCでした。
> - 現在、Majorバグが1件残っていますが、明日修正予定です。
> - 小さく頻繁なPRレビューと第三者レビューは実施済みです。
> この内容で品質会議用のスライド原稿を作成してください。

👉 **AIの動作**: マスタードキュメントの「③テスト後」の基準と照らし合わせ、自動的に4段階評価を行い、**そのままパワポに貼れる4枚構成のスライド原稿**を出力します。

> **ユーザー入力例:**
> 対象フェーズ：スプリント完了・リリース判断（スプリント5）

> - 今回のベロシティは45SPでした（過去3スプリントの平均は42SPです）。
